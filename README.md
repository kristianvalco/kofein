# Kofein ☕

Malá menubarová appka pre macOS, ktorá drží Mac hore (`caffeinate -d -i`) – displej nezhasne, Mac nezaspí.

**Stiahnuť:** https://kristianvalco.github.io/kofein/

## Build

```sh
./build.sh            # skompiluje a nainštaluje do /Applications
./release.sh          # universal build → build/release/Kofein.zip
./release.sh v1.0     # + vytvorí GitHub release so zipom
```

Landing page je v `docs/` (GitHub Pages, branch `main`, priečinok `/docs`).
